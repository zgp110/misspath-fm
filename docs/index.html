MissPath-FM

Flow Matching with Structured Priors for Partially Observed Time Series

When part of a sequence is already observed, the flow should not start from pure noise. MissPath-FM starts the transport near the observed signal and spends it on the entries that are actually missing.

NeurIPS 2026

Genpei Zhang

Department of Computer Sciences, University of Wisconsin–Madison

Paper Code BibTeX

Abstract

A Gaussian source wastes the flow on what is already known.

Flow matching has emerged as a powerful alternative to diffusion models for generative modeling, but standard conditional flow matching is fundamentally misaligned with partially observed time series: starting from an uninformed Gaussian source forces the model to transport even already-observed entries from noise to the target, wasting capacity on trivially known regions.

We propose MissPath-FM, a partial-observation-aware flow matching framework that redesigns the source prior and probability path for incomplete time series. MissPath-FM employs structured source priors (interpolation priors and Gaussian process posterior priors) to initialize the flow close to the observed signal, paired with a missingness-aware smooth path that allocates transport asymmetrically between observed and missing regions.

We evaluate systematically across four datasets, four missingness mechanisms (MCAR, block, MNAR, irregular), two missing ratios, and three sequence lengths (\(T \in \{24, 48, 96\}\)), totaling 48 settings against eight baselines. MissPath-FM wins 29 of 32 settings at \(T{=}48\) and 45 of 48 overall (93.8%). Our ablations reveal a regime-dependent design hierarchy in which no single component suffices: under random missingness the source prior yields a large initial gain, but under structured block missingness it can fail entirely and the learned flow becomes indispensable; the missingness-aware path contributes a further 12%–26% across all regimes. Mechanistically, structured priors shorten observed-region transport by up to 15×, concentrating the velocity field on genuinely uncertain entries.

The bottleneck

Where does the transport go?

Under the linear path \(x_t = (1-t)\,z_0 + t\,x_1\), the expected transport cost splits by observation status. With a Gaussian source, every observed entry still has to be carried from noise to its known value.

Transport cost decomposition (Proposition 1)

\[\mathbb{E}\bigl[\|x_1 - z_0\|^2\bigr] = \mathcal{C}_{\mathrm{obs}} + \mathcal{C}_{\mathrm{miss}}, \qquad \mathcal{C}_{\mathrm{obs}} = \sum_{m_{\tau,d}=1} \mathbb{E}\bigl[(x_{1,\tau,d} - z_{0,\tau,d})^2\bigr]\]
Gaussian source

\(z_0 \sim \mathcal{N}(0, I)\)

For z-scored data each observed entry costs 2, so \(\mathcal{C}_{\mathrm{obs}} = 2\,n_{\mathrm{obs}}\): the cost grows with the number of entries the model already knows. At 50% missingness, about half of the network's capacity goes to them.

Interpolation source

\(z_0 = x_1 + \epsilon\) on observed entries

With \(\epsilon \sim \mathcal{N}(0, \sigma_{\mathrm{obs}}^2)\), \(\mathcal{C}_{\mathrm{obs}} = \sigma_{\mathrm{obs}}^2\, n_{\mathrm{obs}} \to 0\). The flow only has real work to do where values are missing.

Method

Three components, used together in every result

Structured source prior

Start from \(z_0 \sim \mathcal{N}(\mu^{\mathrm{int}}, \Sigma(m))\): piecewise-linear interpolation of the observations, with small noise \(\sigma_{\mathrm{obs}}\) on observed entries and larger \(\sigma_{\mathrm{miss}}\) on missing ones. A GP posterior prior is an optional alternative.

Missingness-aware path

Each entry moves at its own speed, \(\alpha_{\tau,d}(t) = 1-(1-t)^{s_{\tau,d}}\) with \(s_{\mathrm{obs}} > s_{\mathrm{miss}}\). Observed entries settle early, so later in the flow the velocity field effectively works only on the missing ones.

Context-conditioned velocity

A Transformer over time takes \([x_t \,\|\, m \,\|\, \tilde\delta]\) per step (values, mask, time since last observation) plus flow-time embeddings. Inference uses 20 Euler steps, then restores observed entries.

Path, target velocity and loss

\[x_{t,\tau,d} = \bigl(1 - \alpha_{\tau,d}(t)\bigr)\,z_{0,\tau,d} + \alpha_{\tau,d}(t)\,x_{1,\tau,d}, \qquad u_{t,\tau,d} = s_{\tau,d}\,(1-t)^{s_{\tau,d}-1}\,(x_{1,\tau,d} - z_{0,\tau,d})\]
\[\mathcal{L} = \mathbb{E}_{x,\, z_0,\, t}\bigl\| v_{\theta}(x_t, t, c) - u_t \bigr\|_2^2 + \lambda_{\mathrm{obs}}\,\mathcal{L}_{\mathrm{obs}}, \qquad \lambda_{\mathrm{obs}} = 0.1\]

The complete training step

# (i) Interpolation prior
mu    = interp_1d(x_obs, mask)             # piecewise linear in time
sigma = where(mask, 0.1, 1.0)              # sigma_obs << sigma_miss
z0    = mu + sigma * randn_like(mu)

# (ii) Missingness-aware path
s     = where(mask, 2.0, 1.0)              # s_obs = 2, s_miss = 1
alpha = 1 - (1 - t) ** s
x_t   = (1 - alpha) * z0 + alpha * x1
u_t   = s * (1 - t) ** (s - 1) * (x1 - z0)

# (iii) Loss: CFM on all entries + light observed-entry term
err   = (v_theta(x_t, t, ctx) - u_t) ** 2
loss  = err.mean() + 0.1 * (mask * err).sum() / mask.sum()

Why it works

The velocity field moves to the missing entries

With a Gaussian prior, every entry travels a long way from noise. With a structured prior, observed entries barely move, and the miss-to-observed transport ratio rises from 1.1× to 19.2×.
